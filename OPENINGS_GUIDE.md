# Как добавить или обновить дебют

Каждый файл `src/data/openings/*.json` — один курс. Новый файл автоматически появляется в каталоге. Обязательные поля и JSON Schema: [src/lib/schema.ts](src/lib/schema.ts), [docs/schemas/opening.schema.json](docs/schemas/opening.schema.json).

Корневые поля: `schemaVersion: 1`, стабильный `id`, числовая `version`, `title`, `subtitle`, `side` (`w`/`b`), `eco`, `level`, `history`, `idea`, `structure`, массивы `plans`, `opponentPlans`, `mistakes`, `traps`, а также `after`, дерево `root` и линия `practice`.

Пишите для игрока 1000–1200: объясняйте, что атакуется, где слабости и зачем двигать пешку. Разделяйте общие планы и конкретные форсированные комбинации. Для сомнительных гамбитов прямо указывайте материальную цену, объективный риск и способы защиты.

## Дерево

```json
{
  "id": "my-opening-root",
  "comment": "Начальная позиция.",
  "children": [
    {
      "id": "my-opening-e4",
      "move": "e2e4",
      "comment": "Занимаем центр.",
      "arrows": [["d2", "d4"]],
      "highlights": ["e4"],
      "children": [
        { "id": "my-opening-e5", "move": "e7e5", "children": [] },
        {
          "id": "my-opening-c5",
          "move": "c7c5",
          "comment": "Альтернативный ответ.",
          "children": []
        }
      ]
    }
  ]
}
```

Первый ребёнок — основная линия, последующие — альтернативы из **одной и той же** позиции родителя. `move` — UCI, относительно родителя, а не SAN. У корня нет хода; курс начинается с начальной позиции шахмат. Каждый узел имеет уникальный ID в пределах дерева. Не создавайте ссылки на родительские узлы: JSON описывает дерево, не циклический граф.

Комментарий показывается **после** соответствующего хода. `arrows` — пары корректных клеток, `highlights` — список клеток. Не передавайте HTML: текст выводится React как текст. Путь до узла однозначно восстанавливает FEN. Ветка может иметь собственные подветки; возврат ведёт к ближайшему месту отхода от основной линии.

## Практика

`practice` — полная изучаемая последовательность UCI из начальной позиции. Белый ученик делает ходы с индекса 0; чёрный — с индекса 1, после автоматического первого хода белых. Ответы соперника воспроизводятся автоматически. Если линия оканчивается ответом соперника, этот последний ход отбрасывается в упражнении: завершение всегда после хода ученика.

Линия должна совпадать с изучаемым вариантом и сопровождаться понятными объяснениями. Это проверка памяти и понимания конкретного репертуара: другой объективно хороший дебютный ход может не совпадать с выбранной линией. Не обозначайте такое несовпадение объективной шахматной ошибкой в тексте курса.

Для Понциани уже включены ответы `...Nf6`, `...d5`, `...Bc5`, `...d6`. Итальянская содержит обе ветки `5...Na5` и `5...Nxd5?!`, включая продолжение жертвы на f7. Другие курсы — вводные репертуарные уроки, их можно расширять без изменения компонентов.

## Проверка и публикация

```sh
npm run check
npm run test:e2e
```

Проверяются все ветки, повторяющиеся ID узлов, практика и PGN-экспорт. Тест легальности не устанавливает объективную оценку дебюта: теорию и комментарии следует дополнительно проверять. Сохраняйте ID курса, увеличивайте `version` при смысловых изменениях. Внешний тренер должен присылать правку JSON и объяснение через PR; личный прогресс остаётся в приватном репозитории.

Пользовательские варианты свободной студии живут в памяти. Их можно экспортировать в PGN с RAV-ветками и затем использовать как материал для ручного обновления JSON. Импорт PGN в текущей версии загружает основную линию; автоматическое преобразование всех RAV-веток в курс не реализовано.
