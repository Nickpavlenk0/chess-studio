## Оставшаяся проверка владельцем

Вход владельца через GitHub подтверждён, однако при обращении к хранилищу получен `502`. Добавлена защищённая страница `/api/storage-status`, различающая недействительный токен, недоступный репозиторий, недостаточные права и лимиты GitHub. Значения секретов и содержимое прогресса она не показывает. После исправления доступа требуется повторная отправка из исходной вкладки с тем же UUID, подтверждение записи в приватном журнале и проверка повторного чтения. До этого реальная запись результатов не считается подтверждённой.

Точные настройки и порядок проверки приведены в [DEPLOYMENT.md](../DEPLOYMENT.md). Автоматическая публикация Worker выполняется Cloudflare Workers Builds при push в `main`; сайт публикуется GitHub Actions.

## Известные границы текущей версии

- Импорт PGN загружает основную линию; экспорт сохраняет собственные RAV-ветки.
- Временные варианты свободного анализа сохраняются экспортом PGN; автоматически в облако отправляются результаты завершённых упражнений.
- При блокировке сторонних auth cookie на Android после обновления может понадобиться повторный GitHub-вход. Прогресс всё равно загружается из GitHub, не с телефона.
- Неподтверждённая очередь не переживает закрытие вкладки или выгрузку мобильной ОС: это следствие выбранного запрета постоянного локального хранения. Пока вкладка работает, очередь сохраняется при навигации, поддерживает повтор и экспорт.
- Приватный JSON-журнал ограничен 8 MB; архивирование и пагинация потребуют последующего расширения схемы, данные автоматически не удаляются.
