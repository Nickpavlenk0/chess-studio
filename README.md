# Chess Studio

Персональная шахматная академия на русском языке для вдумчивого игрока уровня 1000–1200 рапид. Это учебная студия: в ней нет игры против компьютера, подбора соперников и встроенного ИИ.

## Что работает

- Адаптивная доска: касания и перетаскивание, легальные ходы, шах, рокировка, взятие на проходе, выбор всех четырёх превращений, ориентация, стрелки и выделения. Доступен ввод SAN/UCI с клавиатуры.
- Дерево вариантов: основная линия, вложенные ответвления, комментарии, переход к любому ходу и ближайшему разветвлению, собственные продолжения, экспорт PGN со всеми ветками.
- Диагностика из 15 реальных позиций Lichess (CC0). FEN проверены python-chess; **все ходы ученика** проверены Stockfish 19 на глубине 20. Отчёт: [docs/content-verification.json](docs/content-verification.json).
- Проверка решения без преждевременного раскрытия ответа, автоматические ответы соперника, история неправильных ходов, подсказки, добровольный разбор, повторные попытки.
- Пять дебютных курсов: подробно проработанный Понциани с четырьмя основными ответами чёрных; вводные курсы Итальянской, Хэллоуина, Каро — Канн и Староиндийской. Есть режим воспроизведения основной линии по памяти. Недостатки Хэллоуина указаны прямо.
- Анализ: загрузка FEN, импорт основной линии PGN, создание новых вариантов на доске, экспорт PGN с вариантами. Импорт вложенных PGN-вариантов пока не реализован и обозначен в интерфейсе.
- Личный журнал: подтверждённые результаты, успешность без ошибок и подсказок, категории, ошибки, занятия, диагностики и освоенные линии дебютов. Экспорт JSON включает также неподтверждённую очередь.
- Cloudflare Worker: GitHub OAuth только для владельца, короткая сессия, приватный репозиторий прогресса, идемпотентная запись и обработка конфликтов GitHub.
- Светлая/тёмная темы и три оформления доски. Настройки оформления живут только в памяти вкладки.

## Запуск

Требуется Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Открыть `http://localhost:5173/chess-studio/`. Без `VITE_API_URL` работают все учебные материалы; интерфейс честно сообщает, что облако не настроено. Завершённые ответы остаются в памяти вкладки и **не** обозначаются сохранёнными.

```sh
npm run check           # ESLint, схемы, контент, unit-тесты, production build
pip install python-chess
python scripts/validate-fens.py
npx playwright install chromium
npm run test:e2e        # Chromium: Pixel 7 и desktop
npx wrangler deploy --dry-run
```

В этой среде браузерные тесты используют `/usr/bin/chromium`; в CI — установленный Playwright Chromium. Можно задать `CHROMIUM_PATH`. E2E использует подмену сетевого GitHub/Worker API, а не реальные личные данные.

## Хранение и синхронизация

Постоянное хранилище учебных данных — только GitHub:

| Репозиторий      | Содержимое                                      | Доступ  |
| ---------------- | ----------------------------------------------- | ------- |
| `chess-studio`   | Код, JSON задач и уроков, документация          | Public  |
| `chess-progress` | `progress.json`: история завершённых упражнений | Private |

В браузере нет localStorage, IndexedDB, Service Worker или офлайн-копии прогресса. В оперативной памяти находятся текущее занятие, полученный журнал и очередь отправки. Обычный кэш статических файлов разрешён. Один commit — одно завершённое упражнение; перемещения фигур не создают сетевых записей.

`Сохраняется…` означает отправку. `Сохранено` появляется только после ответа Worker, подтвердившего commit в GitHub. При ошибке ответ остаётся в памяти до повторной отправки; навигация по приложению его не удаляет. Перед закрытием/перезагрузкой вкладки с очередью браузеру передаётся запрос предупреждения, но мобильная ОС может закрыть вкладку без него. Пока сервер не подтвердил запись, не закрывайте вкладку; при необходимости экспортируйте очередь.

HttpOnly cookie содержит только короткую сессию авторизации, **не учебные данные**. После обновления страницы приложение пытается восстановить сессию и заново читает GitHub. Если Android блокирует сторонние cookie между `github.io` и `workers.dev`, достаточно снова нажать «Войти»: OAuth восстанавливает доступ без локального журнала. Для бесшовного восстановления можно использовать свой домен с поддоменами для Pages и Worker. Подробности в [DEPLOYMENT.md](DEPLOYMENT.md).

Свободный анализ и свои временные ветки не синхронизируются автоматически: их можно экспортировать в PGN. Уроки и задания редактируются в JSON через GitHub, затем проходят CI и публикуются.

## Для внешнего тренера

Подключите к ChatGPT оба репозитория и разрешите чтение приватного `chess-progress` и изменения в `chess-studio`. Для новых обычных задач и курсов код интерфейса менять не требуется.

1. Прочитать `chess-progress/progress.json` по [PROGRESS_SCHEMA.md](PROGRESS_SCHEMA.md).
2. Сопоставить `contentId` и `contentVersion` с материалом; для старой версии использовать Git history.
3. Анализировать реальные SAN/UCI, исходные FEN, ошибки, подсказки и полные сыгранные линии. Не приравнивать время размышления к ошибке.
4. Добавить проверенный JSON по [CONTENT_GUIDE.md](CONTENT_GUIDE.md) или [OPENINGS_GUIDE.md](OPENINGS_GUIDE.md).
5. Создать PR и дождаться проверок. Не добавлять личные результаты в публичный репозиторий.

OpenAI API не используется. Доступ внешнего тренера определяется разрешениями подключённой GitHub-интеграции.

## Структура

```text
src/pages/            главная, тренировки, дебюты, анализ, прогресс
src/components/       доска, дерево, упражнение
src/lib/              схемы, проверка ходов, обучение, облачный клиент, статистика
src/data/puzzles/     независимые задачи JSON
src/data/openings/    независимые дебютные курсы JSON
src/data/diagnostic.json  стабильный состав начального теста
worker/               авторизация и ограниченный GitHub API
scripts/              проверка контента, FEN, схем, опциональный Stockfish audit
tests/, e2e/          автоматические проверки
.github/workflows/    тесты, GitHub Pages, ручной deploy Worker
```

[DEPLOYMENT.md](DEPLOYMENT.md) содержит точные действия публикации и необходимые права. Фактическое состояние передачи проекта описано в [docs/DELIVERY.md](docs/DELIVERY.md). Адрес из конфигурации — целевой, до успешного GitHub Actions deployment он не является опубликованным сайтом.

Код: MIT. Позиции Lichess: CC0, ссылки на оригиналы находятся в каждом JSON. `chess.js`, `react-chessboard` и остальные библиотеки сохраняют собственные лицензии. Stockfish используется только при подготовке/проверке материалов и не поставляется в браузерной сборке.
